# E-commerce de Lunettes

Bienvenue sur le projet **E-commerce de Lunettes**, un site de vente en ligne de lunettes développé avec **Flask** et une **base de données MySQL**.

---

## 🛠️ Technologies utilisées

- **Backend :** Python 3, Flask  
- **Base de données :** MySQL / MariaDB avec **pymysql**  
- **Gestion des variables sensibles :** python-dotenv (`.env`)  
- **Frontend :** HTML, CSS, Jinja2 (templates Flask)  
- **Versionning :** Git + GitHub  

---

## 🚀 Fonctionnalités

- Liste des produits (lunettes de vue et solaires)  
- Ajout au panier et gestion du panier  
- Gestion des utilisateurs (connexion / inscription / session)  
- Consultation de la base de données MySQL pour les produits et utilisateurs  
- Interface simple et responsive avec templates Flask
